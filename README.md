# Featuring Work with Python and SQL Programming Languages

## Web Scraping, Data Analysis, Visualization, and Statistical Tests Using Python and SQL

#### This repository showcases data analysis, data visualization, and statistical testing work with the use of Python and SQL programming languages. 

In the enclosed files, datasets were analyzed and visualized using different libraries, including: 
- pandas
- seaborn
- matplotlib

The types of visualizations involved boxplots, bar plots, scatter plots, and histograms. 

Also, various statistical tests were done using SciPy and statsmodels libraries. Those tests include:
- Levene's test
- T-test
- ANOVA test
- Pearson correlation test
- Linear regression model
